## 🚀 راه‌اندازی سریع (دستورالعمل کامل)

### ۱. ساخت ربات تلگرام
1. به [@BotFather](https://t.me/BotFather) برو
2. دستور `/newbot` را بزن
3. اسم ربات را بگذار: `یارا` (یا هر اسمی)
4. یوزرنیم ربات را انتخاب کن (مثلاً `YaraAI_bot`)
5. **توکن** را کپی کن (مثل `7123456789:AAH...`)

### ۲. گرفتن کلید Gemini رایگان
1. برو به [Google AI Studio](https://aistudio.google.com/app/apikey)
2. با اکانت گوگل وارد شو
3. **Create API Key** بزن
4. کلید را کپی کن (مثل `AIzaSy...`)

### ۳. کلون کردن پروژه
```bash
git clone https://github.com/stgddgd075-stack/Yara-Telegram-Bot.git
cd Yara-Telegram-Bot
npm install
```

### ۴. تنظیم کلیدها
فایل `.env` بساز:
```bash
cp .env.example .env
```
سپس داخل `.env` این دو خط را پر کن:
```
BOT_TOKEN=توکن_ربات_از_BotFather
GEMINI_API_KEY=کلید_جمینی_از_AI_Studio
```

### ۵. اجرای ربات
```bash
npm start
```


## ☁️ دیپلوی روی Render (رایگان و ۲۴ ساعته)

1. برو به [render.com](https://render.com) و با GitHub لاگین کن
2. **New → Web Service**
3. مخزن `stgddgd075-stack/Yara-Telegram-Bot` را انتخاب کن
4. تنظیمات:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
5. در بخش **Environment** این دو متغیر را اضافه کن:
   - `BOT_TOKEN` = توکن ربات
   - `GEMINI_API_KEY` = کلید Gemini
6. **Create Web Service** بزن

بعد از دیپلوی، ربات ۲۴ ساعته کار می‌کند (روی پلن رایگان ممکن است گاهی بخوابد).
